## What it does

`VERIFIED_STATIC` Checks or refreshes saved data used for comparisons and external indicators. Evidence: `Stata/plus/p/pea_dataupdate.ado:L113-L154`.

## Syntax


All named options are inside the optional brackets. Explicit guards and practical input needs are stated below. `varname` means one variable; `varlist` means one or more variables. A string option takes text. `Stata/plus/p/pea_dataupdate.ado:L84-L86`.

## What it expects you to have ready

- `VERIFIED_STATIC` The exact declaration contains the existing duplicate-PPP-option risk P0-01. The following cache behavior describes the body; successful execution is not established. - `VERIFIED_STATIC` Recognized cache types are `MPM`, `PIP`, `GMI`, `PEB`, `WDI`, `POP`, `CLIMRISK`, `EXPOSURE`, `LIST`, `UNESCO` and `CLASS`. They are stored under PERSONAL `pea/`. Evidence: `Stata/plus/p/pea_dataupdate.ado:L116-L129`.
- `VERIFIED_STATIC` Without `update`, a missing cache or one older than 30 days triggers a refresh. A requested release different from the cached release label also triggers a refresh. - `EXTERNAL_DEPENDENCY` With a requested release or PPP year, the internal PIP identity check compares returned identifiers and requires a PROD server identity. Unavailable identity information or a mismatch can stop the update. Availability of PIP, DLW and WDI is external to this package. Evidence: `Stata/plus/p/pea_dataupdate.ado:L865-L924`.
