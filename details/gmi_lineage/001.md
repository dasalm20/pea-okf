# Cross-module dependencies

The current production family and separate QA family have source-defined inputs and outputs, but no verified production patch bridge. The execution/dataset graphs enumerate demonstrated paths and candidate relationships separately.

1. 01aa and 01ab independently load the same selected GMD ALL survey family. They do not pass a modified industry variable to each other: each executes its own fallback. Thus changing 01aa's replacement does not automatically change 01ab results. Evidence: `01.Programs/01aa-GMI extended indicators.do:L139,L262-L265`; `01.Programs/01ab-GMI extended indicators labor ind.do:L212,L332-L335`.
2. 01b loads GPWG for welfare statistics and ALL separately for urban/sector decomposition. Later-endpoint ALL fallback does not mutate the earlier GPWG data already used for GIC/DR/SK. Evidence: `01.Programs/01b-GMI extended indicators spells.do:L296-L344,L448-L478,L480-L584`.
3. Format reads allgroups1, PNP1, GIC, decomp1/decomp2, labor_sub and prosg_decomp. Elasticity is a separate direct PEA writer. Evidence: `01.Programs/02-GMI format.do:L52,L285,L369,L394-L395,L422,L635`; `01.Programs/01c-GMI extended spells pov elasticity.do:L180-L194`.
4. Reporting metadata is attached after aggregation. Its merge keys and drops can affect retained outputs independently of economic formulas. Missing metadata for ISO3 is explicitly dropped in poverty/labor paths. Evidence: `01.Programs/02-GMI format.do:L169-L178,L543-L553`.
5. EAP assembler introduces GMD-compatible names, while diagnostics renames those fields `_p_*` for comparison. No active production call loads the local EAP outputs or `_gmdpatch_fixid`. A proposed/intended patch is not an implemented dependency. Evidence: `04.Checks_Add_reharmonization_results/code/99-build_eap_local.do:L414-L428,L541`; `04.Checks_Add_reharmonization_results/code/99-gmdpatch_diagnostics.do:L517,L553-L616`; production source inventory/search bounded by manifest.
6. The archive PIP GIC workflow has its own binned-data pathway and CSV output. Current master checks the manual input but does not invoke this archived workflow. Evidence: `01.Programs/archive/PIP to GIC and Decomposition data.do:L45-L117`; `01.Programs/00-Master.do:L144-L162,L271-L278`.

Potential impacts are conditional. Modifying the delivered primary industry field can affect all three current analysis modules, but changing a single in-memory replacement affects only that module unless its output is subsequently consumed. Changing annual industry in external microdata affects 01aa/01ab only where primary is missing and can affect current 01b's later endpoint only under that same fallback condition. The raw earlier endpoint remains a separate boundary. The per-indicator table in `reference_period_audit.md` makes these distinctions explicit.
