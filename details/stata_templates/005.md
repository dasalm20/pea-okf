Welfare option: `onewelfare(welfppp)` with `oneline(pline300)`.

`VERIFIED_STATIC` The direct template supplies `weight_p`; `pea figures` now also forwards its resolved analytic weight and the caller’s `missing` flag to Figure 16. `Stata/plus/p/pea_figures.ado:L482-L495`.

```stata
confirm new file "pea_figure16.xlsx"

* GMD example conversion; use only with matching annual welfare and factors.
gen double welfppp = welfare/cpi2021/icp2021/365
label variable welfppp "Daily welfare (2021 PPP)"
gen double pline300 = 3.00
label variable pline300 "3.00 per day (2021 PPP)"
gen byte head = relationharm==1 if relationharm~=.
label define pea_head 1 "HH head", replace
label values head pea_head
gen byte married = marital==1 if marital~=.
gen byte nowork = lstatus==2|lstatus==3 if lstatus~=.
label define pea_nowork 0 "Working" 1 "Not working", replace
label values nowork pea_nowork

pea_figure16 [aw=weight_p], ///
    onewelfare(welfppp) oneline(pline300) year(year) age(age) male(male) edu(educat4) ///
    urban(urban) hhhead(head) married(married) hhsize(hsize) hhid(hhid) pid(pid) lstatus(nowork) ///
```
