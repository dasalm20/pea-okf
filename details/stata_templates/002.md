## pea_table4

Welfare option: `welfare(natwelfare)` with `povlines(natline)`.

`EXTERNAL_DEPENDENCY` Household and person IDs, relationship, marital status, school attendance, services and assets must use the GMD codes described in [helper contracts](../stata_commands/004.md#s-8d6b513090f6244e-l7).

`VERIFIED_STATIC` Call options: `Stata/plus/p/pea_table4.ado:L22-L22`.

```stata
confirm new file "pea_table4.xlsx"
putexcel set "pea_table4.xlsx", sheet("Contents") replace
putexcel A1 = "PEA output"
putexcel clear

* Supply the correct national values before running this block.
confirm numeric variable natwelfare natline
gen byte head = relationharm==1 if relationharm~=.
label define pea_head 1 "HH head", replace
label values head pea_head
gen byte married = marital==1 if marital~=.
gen byte nowork = lstatus==2|lstatus==3 if lstatus~=.
label define pea_nowork 0 "Working" 1 "Not working", replace
label values nowork pea_nowork

pea_table4 [aw=weight_p], ///
    welfare(natwelfare) povlines(natline) year(year) age(age) male(male) edu(educat4) ///
    urban(urban) hhhead(head) married(married) hhsize(hsize) hhid(hhid) pid(pid) lstatus(nowork) ///
    empstat(empstat) industrycat4(industrycat4) school(school) ///
    services(imp_wat_rec imp_san_rec electricity) assets(tv car cellphone computer fridge) ///
    pppyear(2021) excel("pea_table4.xlsx")
```
