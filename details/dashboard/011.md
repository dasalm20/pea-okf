## What to capture when this folder is built

The four original capture priorities are preserved verbatim:

1. **Ingestion**: which files it reads, from where, on what schedule, and how a refresh is triggered. This is the most common source of "the dashboard is out of date" questions.
2. **Transformations applied after ingestion**: any rounding, rescaling, relabelling, year selection or filtering done in R rather than upstream. These are invisible to anyone reading the Stata side and are a likely source of small unexplained differences.
3. **Label-to-field mapping**: what each displayed row is called in the UI versus the underlying field name. The UI label and the source field frequently disagree about the sample, for example an age universe shown as 15+ for a field computed on 15-64.
4. **Which year it selects** when several are available for a country, and whether that matches the Stata package's rule.

Item 3 is the highest priority. A displayed label that misstates the sample will be quoted by readers who never see the code.

# Display mapping record

Coverage: `PARTIAL_STATIC`. [index/display_mappings.jsonl](../../lookup/sources/Dashboard/index/display_mappings.jsonl.md) contains one record per active configured output template.

- id: stable local identifier, figure sheet:field or table ID:row-template:column-template.
- kind: figure_series or table_cell.
- active: true for this index; inactive workbook tables are documented separately and excluded.
- card, section, worksheet: active YAML identity.
- field: literal dashboard var key, never an assertion of cross-product identity.
- figure records: label, label_full, filter, axes and exact workbook config_locator.
- table records: row_label, column_label, keys and row_locator/column_locator. Country/year placeholders are not expanded into invented observations.
- evidence_status: VERIFIED_STATIC for the binding itself.
- evidence_scope: explicitly excludes rendered values, populated cells and authenticated upstream identity.
- source_refs: real peaApp text-file line ranges at the provenance pin. Binary workbook locations use cell coordinates, not line citations.

Counting rule: each unique active figure/field pair counts once; the repeated risk_any entry in one YAML filter does not add a second mapping. Active table variable/subvariable rows are crossed with configured columns, matching the table helper. No country/year/spell/subgroup expansion beyond the explicit table axes is counted. Field definitions and subgroup dictionaries are supplemental and are not added to the 588 count.

No mapping asserts a statistical denominator unless separately established in the narrative records. Evidence concerning the source configuration cannot be promoted to a claim about a running deployment.
