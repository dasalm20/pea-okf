Open the file inventory (deployment lookup: lookup/sources/GMI_extended/architecture/file_inventory.md.md) first, choose the full current, archive, or QA program name, and follow its Workflow link. This folder holds one execution-order document per indexed Stata workflow, including exact command text, source citations, enclosing controls, block IDs, and recorded variable/dataset relationships. Filenames combine the source filename's stem before its first hyphen, with spaces replaced by underscores, a hyphen, and the first six hexadecimal characters of its file ID; archived workflows also have an `archive-` prefix, and the matching source map (deployment lookup: lookup/sources/GMI_extended/source_maps/README.md.md) uses the same basename. Coverage remains **PARTIAL_STATIC**: lexical statement coverage does not establish complete runtime schemas or macro expansion, and candidate relationships remain `INFERRED`; use ANSWERS.md (deployment lookup: lookup/sources/GMI_extended/ANSWERS.md.md) for a short explanation before opening a long workflow.
