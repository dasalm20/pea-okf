# Welfare, weights and time fields

`welfare` is imported GMD welfare. Daily PPP welfare is `welfare/cpi<ppp>/icp<ppp>/365`, floored at .25 (2017) or .28 (2021). The code implies a daily conversion but does not supply the original welfare questionnaire period or unit metadata. 01ab drops negative converted welfare; 01aa and spell blocks floor negative values instead. Evidence: `01.Programs/00-Master.do:L196-L208`; `01.Programs/01aa-GMI extended indicators.do:L454-L467`; `01.Programs/01ab-GMI extended indicators labor ind.do:L425-L431`; `01.Programs/01b-GMI extended indicators spells.do:L310-L315`.

01aa/01ab ALL select `weight_p` when present, otherwise `weight`. Presence is tested, not nonmissing completeness. Missing ordinary welfare/weight rows are dropped. Head summaries use head-only values on these person-level records. `h` copies the chosen weight and is raw-summed to `noind`; `nohh` is renamed from a command `count(year)` result, so it must not be assumed to count unique households. Evidence: `01.Programs/01aa-GMI extended indicators.do:L143-L153,L338-L403,L484-L497,L521-L541`; `01.Programs/01ab-GMI extended indicators labor ind.do:L246-L255,L506-L554`.

Production `year` begins as survey-list `years` converted to numeric. Format preserves survey year as `surv_year` and replaces visible `year` with joined `rep_year`. `ref_year` is metadata; it does not drive the labor fallback. Elasticity joins PIP year (first renamed rep_year) to price metadata, then joins on survey year to the spell endpoint list. Evidence: `01.Programs/01aa-GMI extended indicators.do:L61-L63`; `01.Programs/02-GMI format.do:L169-L178`; `01.Programs/01c-GMI extended spells pov elasticity.do:L95-L108,L145-L179`.

Spell `period`/`spell` is a separately supplied comparability grouping/label; formulas use the numeric endpoint-year difference. Annualized log prosperity changes divide by that difference. Elasticity divides log poverty change by log GDP change (or the two annualized growth rates); no zero-denominator/positive-value checks are visible. Evidence: `01.Programs/01b-GMI extended indicators spells.do:L278-L287,L424-L436`; `01.Programs/01c-GMI extended spells pov elasticity.do:L173-L179`.
