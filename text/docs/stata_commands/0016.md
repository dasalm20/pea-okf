## What it expects you to have ready

- `VERIFIED_STATIC` Load the variables named by the numeric options before the call. The brackets in the declaration make these options syntactically optional; they do not guarantee a complete calculation when omitted. Evidence: `Stata/plus/p/pea_table13a.ado:L22-L22`.
- `VERIFIED_STATIC` This table’s `setting()` declaration does not build GMD mappings. Supply prepared variables explicitly; use the [helper contracts](0004.md#L500-L517) for their shapes. Evidence: `Stata/plus/p/pea_table13a.ado:L22-L45`.
- `VERIFIED_STATIC` Each spell gives a first and second survey year. Both years need usable welfare and matching poverty-line variables for each requested calculation. Evidence: `Stata/plus/p/pea_table13a.ado:L138-L173`.
- `VERIFIED_STATIC` The sector field must have nonmissing values in every requested year. It is normally the urban/rural field. Evidence: `Stata/plus/p/pea_table13a.ado:L103-L108`.

## Easy to confuse

- `VERIFIED_STATIC` `natwelfare()` pairs with `natpovlines()` in national units. `pppwelfare()` pairs with `ppppovlines()` in the selected PPP units. `year()` is a survey-year variable, not the PPP conversion year. Evidence: `Stata/plus/p/pea_table13a.ado:L22-L22`.
- `VERIFIED_STATIC` `nooutput` uses `save()` for an intermediate dataset. `excel()` selects workbook export; the command rejects using it together with `nooutput`. Evidence: `Stata/plus/p/pea_table13a.ado:L40-L53`.

## Errors this command can produce

`VERIFIED_STATIC` Message text below is copied from this command. Macro names are source templates that are replaced when printed. `INFERRED` The explanation is a reading of the condition, not a diagnosis of a particular run. The [full error index](../stata_errors/0001.md#L6-L23) also includes helpers, external-data notices and missing-output checks.

| Literal message | What it usually means |
|---|---|
| `` Welfare in `pppyear' PPP is adjusted to a floor of ${floor_} `` | Notice: welfare values below the selected floor are replaced by that floor. `Stata/plus/p/pea_table13a.ado:L97-L97` |
| `` Unable to open the data `` | The source contains this data-loading message, but the command does not declare using(). Normal reachability of this branch is not established. `Stata/plus/p/pea_table13a.ado:L32-L32` |
| `` Need at least two years, i.e. 2000 2004 `` | The requested survey periods do not supply at least two year tokens. `Stata/plus/p/pea_table13a.ado:L49-L49` |
| `` There are different years requested, and some not available in the data. `` | At least one requested year was not found among the available years. `Stata/plus/p/pea_table13a.ado:L115-L115` |
| `` Requested: `keepyears'. Available: `yrlist' `` | This shows requested and available year lists for the preceding warning. `Stata/plus/p/pea_table13a.ado:L116-L116` |
| `` Cant have both nooutput and excel() options `` | The code rejects combining nooutput with an Excel destination. `Stata/plus/p/pea_table13a.ado:L45-L45` |
| `` No values for `urban' for year `y'. Please select other years, or a different sector variable. `` | The requested group variable has no usable values for the displayed year. `Stata/plus/p/pea_table13a.ado:L106-L106` |
| `` Sector/urban variable must be define in urban() `` | The urban/rural grouping variable was not supplied. `Stata/plus/p/pea_table13a.ado:L37-L37` |
