## What it expects you to have ready

- `VERIFIED_STATIC` The exact declaration contains the existing duplicate-PPP-option risk P0-01. The following cache behavior describes the body; successful execution is not established. See [ISSUES.md](../stata_errors/0004.md#L655-L672). Evidence: `Stata/plus/p/pea_dataupdate.ado:L84-L103`.

- `VERIFIED_STATIC` Without `update`, a missing cache or one older than 30 days triggers a refresh. A requested release different from the cached release label also triggers a refresh. A fresh primary file does not establish that the whole cache bundle is complete (P2-07). Evidence: `Stata/plus/p/pea_dataupdate.ado:L132-L154`.
- `EXTERNAL_DEPENDENCY` With a requested release or PPP year, the internal PIP identity check compares returned identifiers and requires a PROD server identity. Unavailable identity information or a mismatch can stop the update. Availability of PIP, DLW and WDI is external to this package. Evidence: `Stata/plus/p/pea_dataupdate.ado:L865-L924`.
