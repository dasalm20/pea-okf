## Sample, weights and output

Explicit weights preserve their original type in `_ebin` and `collapse`; no weight creates unit analytic weights. `Stata/plus/p/pea_figure3a.ado:L113-L113`; `Stata/plus/p/pea_figure3a.ado:L283-L343`; `Stata/plus/p/pea_figure3a.ado:L384-L407`.

`VERIFIED_STATIC` Uses preserve/restore; results are exported before restoration. Creates Figure3a sheet once, then places each graph at A5 + 25 rows per group and its code at O7 onward. Numeric backing data start at O11 with variable names and nolabel. Optional save captures that result; old explicit `r(vargic)`/`r(varlbl)` assignments were removed. `Stata/plus/p/pea_figure3a.ado:L73-L73`; `Stata/plus/p/pea_figure3a.ado:L608-L719`.

`INFERRED` Repeated identical spells attempt to generate the same `gic_start_end` name twice. Comparability is checked across the initial sample, not independently for each by category; a group lacking one endpoint can yield missing growth. Five or more groups also place graph-code cells in the O11+ data area subsequently exported. These conditions require runtime confirmation. `Stata/plus/p/pea_figure3a.ado:L173-L228`; `Stata/plus/p/pea_figure3a.ado:L384-L445`; `Stata/plus/p/pea_figure3a.ado:L505-L542`; `Stata/plus/p/pea_figure3a.ado:L642-L703`.

## What it expects you to have ready

- `VERIFIED_STATIC` Load the variables named by the numeric options before the call. The brackets make these options syntactically optional; they do not guarantee a complete calculation when omitted. Evidence: `Stata/plus/p/pea_figure4.ado:L22-L22`.
- `VERIFIED_STATIC` The report workflow produces this figure through `pea figures`; see the [pea_figures record](0014.md#L540-L557) for the entry options and preparation. The declaration here belongs to the individual producer. Evidence: `Stata/plus/p/pea_figures.ado:L227-L227`.
- `VERIFIED_STATIC` Have observations for both years in each requested spell. Write pairs as `spells(0000 0000; 0000 0000)`: a space between the years and a semicolon plus a space between pairs. These are example years, not required dates. Evidence: `source-ref-98abd6b846add01bfcbe.do:L143-L143`.
- `VERIFIED_STATIC` This producer does not call the GMD mapper. Prepare its input fields before a direct call; `setting(GMD)` does not build them here. Evidence: `Stata/plus/p/pea_figure4.ado:L22-L317`.
- `VERIFIED_STATIC` Have a literal `year` field for the within-year line check. If a poverty line differs across groups in a year, supply the group field through `idpl()`. Evidence: `Stata/plus/p/pea_figure4.ado:L55-L66`.
- `EXTERNAL_DEPENDENCY` The calculation calls the external `drdecomp` and `skdecomp` commands. The [setup record](0015.md#L223-L240) lists their installation checks. Evidence: `Stata/plus/p/pea_figure4.ado:L155-L175`.
- `VERIFIED_STATIC` Supply the intended observation weight. When no weight is supplied, the command creates a weight of 1. Evidence: `Stata/plus/p/pea_figure4.ado:L77-L83`.
- `VERIFIED_STATIC` With `comparability()`, have a literal `year` field matching the supplied survey-year variable; the spell check reads that fixed field name. Evidence: `Stata/plus/p/pea_figure4.ado:L124-L140`.

## Easy to confuse

- `VERIFIED_STATIC` This command accepts `onewelfare()` with `oneline()` naming the matching poverty-line variable. The option takes a variable, not a numeric line value. Evidence: `Stata/plus/p/pea_figure4.ado:L22-L22`.
