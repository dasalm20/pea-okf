## What it expects you to have ready

- `VERIFIED_STATIC` Load the variables named by the numeric options before the call. The brackets make these options syntactically optional; they do not guarantee a complete calculation when omitted. Evidence: `Stata/plus/p/pea_figure8.ado:L22-L22`.
- `VERIFIED_STATIC` The report workflow produces this figure through `pea figures`; see the [pea_figures record](0014.md#L540-L557) for the entry options and preparation. The declaration here belongs to the individual producer. Evidence: `Stata/plus/p/pea_figures.ado:L308-L308`.
- `VERIFIED_STATIC` With `fgtvars`, `_fgt0_<welfare>_<line>` must already exist for each selected welfare/line pair. It is 1 below the line and 0 otherwise, with missing values outside the usable sample. This is a prepared poverty indicator, not raw welfare. See [prepared fields](0004.md#L646-L692). Evidence: `Stata/plus/p/pea_figure8.ado:L85-L92`.
- `VERIFIED_STATIC` The poverty helper builds those fields only for nonmissing welfare and lines in the selected sample. Without `fgtvars`, pre-existing fields with the same names cause its creation check to stop. Evidence: `Stata/plus/_/_pea_gen_fgtvars.ado:L24-L48`.
- `VERIFIED_STATIC` Supply age in years and a labeled numeric sex field. Age groups run from 0–4 to 75–79; ages 80 and above do not receive a group. Evidence: `Stata/plus/p/pea_figure8.ado:L37-L57`.
- `VERIFIED_STATIC` The figure keeps the latest survey year and calculates poverty rates within each sex and age group. Evidence: `Stata/plus/p/pea_figure8.ado:L95-L138`.
- `VERIFIED_STATIC` Supply the intended observation weight. When no weight is supplied, the command creates a weight of 1. Evidence: `Stata/plus/p/pea_figure8.ado:L66-L72`.
